# Nexa Homepage

I chose **Material UI (MUI)** to build this responsive React homepage.
The project uses Vite and React.
I installed the library with `npm install @mui/material @emotion/react @emotion/styled`.
I also installed the MUI icon package with `npm install @mui/icons-material`.
Material UI saved me from writing responsive navigation, buttons, cards, drawers, and progress-bar CSS by hand.
